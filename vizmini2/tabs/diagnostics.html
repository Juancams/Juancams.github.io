Diagnostics

Four views in one tab; choose which one to start with when you create it.

Log

/rosout with a minimum level (DEBUG, INFO, WARN, ERROR, FATAL; INFO and above by default), a filter by node or text, and the last 2000 lines. Pause, Resume and Clear.

Diagnostics

/diagnostics grouped by level, like rqt_robot_monitor. Tap an entry to see its values.

Echo

The live messages of any topic. Pick the type with Type… and the QoS with QoS: Best effort receives from any publisher, Reliable, or Transient local to get the last message kept by the publisher (for example /map).

Plot

Up to four numeric fields of a topic over the last 30 seconds. Messages with no numbers (maps, images, point clouds) can’t be plotted.
